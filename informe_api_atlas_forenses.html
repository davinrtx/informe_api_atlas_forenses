Resumen Ejecutivo

Visión general del sistema de integración API REST para consultas forenses.

Alcance del Servicio

  • Consulta de sedes forenses registradas (morgues)
  • Búsqueda de cadáveres no identificados (fase post-mortem)
  • Consulta de coincidencias algorítmicas ante-mortem vs. post-mortem
  • Acceso de solo lectura para organismos externos

Restricciones del Token Demo

  • Permiso único: organismo:buscar
  • Métodos HTTP permitidos: únicamente GET
  • No permite crear, modificar ni eliminar registros
  • Rate limit: máximo 60 solicitudes por minuto
Nota institucional: Este informe corresponde a la documentación de demostración para el profesor. El token proporcionado es de uso exclusivo para fines académicos y de integración de prueba. Toda consulta queda registrada en el sistema de auditoría.

Arquitectura de Seguridad

El sistema implementa cuatro capas de protección para garantizar la integridad y confidencialidad de los datos forenses.

CapaMecanismoDescripción
Autenticación Laravel Sanctum — Bearer Token Verifica la identidad del solicitante mediante token de acceso personal. El token debe enviarse en el header Authorization con prefijo Bearer.
Autorización Middleware api.readonly Restringe operaciones a método GET únicamente. Implementa whitelist de direcciones IP autorizadas y verificación de habilidades (abilities) del token.
Rate Limiting throttle:60,1 Limita a 60 solicitudes por minuto por IP/token. Al exceder el límite, el sistema responde con código HTTP 429.
Versionado Prefijo /api/v1/ Aísla cambios futuros de la API, permitiendo evolución sin afectar integraciones existentes.
Advertencia de seguridad: El token de demostración posee permisos mínimos. En producción, cada organismo externo recibe un token único con alcance restringido a sus jurisdicciones y funciones específicas. La rotación de tokens se realiza cada 90 días.

Flujo de Autenticación

Flujo # 1. El cliente envía solicitud con token Bearer
GET /api/v1/sedes HTTP/1.1
Host: 127.0.0.1:8000
Authorization: Bearer 9|x67VdjgIZRKb7UDzeQZvusp98cZ4H09tJSQPCUYob9f0ae7a
Accept: application/json

# 2. Sanctum valida el token y recupera el usuario
# 3. El middleware api.readonly verifica:
# - Método HTTP == GET
# - IP en whitelist
# - Habilidad 'organismo:buscar' presente
# 4. Si pasa validaciones, se ejecuta el controlador
# 5. Rate limiter cuenta la solicitud contra el límite de 60/min

Endpoint 2 — Buscar Cadáveres No Identificados (Fase PM)

GET /api/v1/buscar-cadaver

Retorna cadáveres con resultado de identificación NEGATIVO. Acepta filtros opcionales por sexo, rango de edad y palabra clave de tatuaje. Respuesta paginada (15 registros por página).

Códigos de Respuesta HTTP

Catálogo de respuestas de error que la API puede retornar, ordenadas por severidad.

CódigoSignificadoCausa ProbableAcción Recomendada
401 Unauthorized Token inválido, expirado o no enviado en el header Authorization. Verificar que el token esté activo y correctamente formateado con prefijo Bearer.
403 Forbidden Dirección IP no autorizada o habilidad insuficiente en el token. Contactar al administrador del sistema para solicitar acceso desde la IP actual o revisar permisos del token.
404 Not Found El recurso solicitado no existe (ej. número de denuncia inexistente). Verificar la URL y los parámetros. Confirmar que el identificador sea correcto.
422 Unprocessable Entity Error de validación en los parámetros de consulta. Revisar el formato y tipo de datos enviados. Consultar la documentación de parámetros.
429 Too Many Requests Rate limit excedido (> 60 solicitudes por minuto). Implementar lógica de reintento con backoff exponencial. Reducir frecuencia de peticiones.
Importante: Todas las respuestas de error incluyen un cuerpo JSON con los campos error y message. Se recomienda registrar estos códigos en los logs de integración para facilitar diagnósticos.

Guía de Importación en Postman

Procedimiento paso a paso para importar la colección de pruebas de la API Atlas Forenses.

1
Abrir Postman

Iniciar la aplicación Postman (versión web o de escritorio).

2
Importar colección

Hacer clic en Import → seleccionar la pestaña Raw text.

3
Pegar JSON de la colección

Copiar el bloque JSON completo que se muestra a continuación y pegarlo en el campo de texto.

4
Confirmar importación

Postman detectará automáticamente la colección. Hacer clic en Import para finalizar.
